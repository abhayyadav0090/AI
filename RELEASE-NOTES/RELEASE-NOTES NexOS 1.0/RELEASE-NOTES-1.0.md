# NexOS 1.0 — Front-end only

NexOS began in March 2026 from a simple HTML and CSS assignment: a "Daily Routine Timeline" web page.

## What it was
- A front-end only app. There was no server or database behind it.
- A Kanban board, a to-do list and a focus timer.
- The look and themes were changed several times during this phase.

## Notes
- Per-version notes were not kept for the 1.x phase, so this note summarises the 1.0 series.
- The next series, 1.1, added Google sign-in and NexAI. See `RELEASE-NOTES-1.1.md`.

# NexOS 4.7.0 — Native Shell Study Studio, Cross-Module Polish & Accessibility Release

**Release version:** 4.7.0
**Release date:** 2026-11-28

## Highlights
- **Study Studio integrated into the native NexOS shell (`#view-study`, `#pane-study`, `public/study.js`):** Embedded Study Studio directly inside the Classic `#view-study` section and Enterprise `#pane-study` view (`role="region"`, `aria-modal="false"`, `data-shell="embedded"`), keeping the persistent left sidebar, global top toolbar, ambient backdrop (`background: transparent`), theme tokens (`--k-bg`, `--k-bg-solid`, `--k-soft`, `--k-line`, `--k-radius`), and mobile bottom-navigation clearance (`calc(70px + env(safe-area-inset-bottom, 0px))` on Enterprise; `--nex-study-bottom` on Classic) consistent across all six tabs (`Tutor`, `Quiz`, `Cards`, `Mindmap`, `Revision`, `Library`), while preserving `[data-shell="standalone"]` fallback when a host container is absent.
- **Dashboard prioritization, live `NexHabits` streaks & real KPI trends (`public/app.js`, `public/index-redesign.html`):** Ordered Dashboard priority lists with overdue items first (`enterpriseOpenTasksSorted()` in Enterprise and Classic urgency sorting with `.due-chip.overdue` / `.task-due-chip.overdue`), computed live `NexHabits` streaks in Enterprise `#dash-habits-container .streak-pill`, drove `#kpi-tasks-trend`, `#kpi-focus-trend`, and `#kpi-habits-trend` from real task/focus/habit state, converted Enterprise priority completion controls to accessible `<button class="task-check-circle">` buttons, and opened `#modal-task-editor` on priority row click.
- **Kanban `#tags` & overdue filtering with Board/List parity (`public/index.html`, `public/app.js`, `public/ui.js`, `public/index-redesign.html`):** Added `#classic-kanban-filter-bar`, `#kanban-search-input`, `setClassicKanbanFilter()` / `filterClassicKanban()` (`All`, `Overdue`, `High`, `Medium`, `Low`), and `taskMatchesClassicFilter()` parity in Classic `#task-list-view`, alongside Enterprise `Overdue` filter pills and `#kanban-search-input` `#tag` search (`filterKanbanSearch()`, `filterKanbanPriority('overdue', ...)`).
- **Accessible Calendar scheduling & Habit creation modals (`public/index-redesign.html`):** Replaced native `window.prompt()` dialogs in Enterprise Calendar hour slots (`scheduleTaskAtHour()`) and Habit creation (`openNewHabitModal()`) with `#modal-slot-schedule` (supporting `assignExistingTaskToHour()` and `submitSlotNewTask()`) and `#modal-new-habit` (`submitNewHabitModal()` with weekly goal selection), retaining a guarded fallback only if the modal markup is absent.

## Improvements
- **Study Studio keyboard shortcuts & mobile targets (`public/study.js`):** Added capture-phase `Escape` handling so open dropdowns, sidebars, overlay dialogs, Day Derailed, or Zen mode dismiss cleanly before Study Studio exits, wired Quiz (`1`–`4` / `a`–`d` answer pick, `Enter` next) and Flashcards (`Space`/`Enter` flip, `1`/`ArrowLeft` needs-practice, `2`/`ArrowRight` mastered) keyboard shortcuts outside text inputs, and ensured mobile starter/back buttons meet `>= 36px` touch targets without horizontal overflow.
- **Pomodoro persistence, auto-start cleanup & midnight rollover (`public/app.js`, `public/index-redesign.html`):** Persisted running focus/break timers across reloads (`nexos_classic_pomo_v1` / `restoreClassicPomodoro()` in Classic; `nexos_enterprise_pomo_v1` / `restoreEnterprisePomodoroSession()` in Enterprise), canceled queued auto-start timers (`cancelClassicAutoStart()`, `cancelEnterpriseAutoStart()`) on pause/reset/skip/mode switches, dynamically updated Enterprise `#tab-pomo-long` labels in `updatePomoDurations()` when `#cfg-long-min` changes, and refreshed daily views/analytics when clock ticks cross midnight.
- **Offline Analytics fallbacks & insight summaries (`public/app.js`, `public/index-redesign.html`, `public/style.css`):** Rendered local completion and focus summary boxes (`.chart-unavailable`, `.offline-chart-stat` in Classic; `#analytics-insights-strip`, `.analytics-offline-box`, `.analytics-offline-bars` in Enterprise) whenever `Chart.js` is unavailable offline.
- **WCAG contrast, breadcrumb clipping & mobile touch targets (`public/style.css`, `public/design.css`, `public/index-redesign.html`):** Updated light-theme contrast on `[data-theme="apple-light"] .dash-task-item.done .task-check-circle`, `[data-theme="apple-light"] .habit-day-check-btn.checked`, and dark-theme checked habit buttons (`#052e16`), unclipped Enterprise mobile/tablet topbar breadcrumbs (`#topbar-view-title`) and sign-in pills (`.topbar.has-signin .topbar-signin`), and normalized `>= 36px` mobile action buttons (`@media (max-width: 900px), (pointer: coarse)`).

## Fixes
- **Note navigation race fix (`public/app.js`):** Updated `openNoteFromDash(id)` to call `openNote(id)` synchronously right after `switchView('notes')`, removing the 100 ms `setTimeout` race that left newly navigated note editors momentarily blank.
- **Scroll lock state cleanup (`public/study.js`):** Added explicit `hasCapturedScroll` tracking alongside `captureBackgroundScroll()` / `unlockBackgroundScroll()` so exiting embedded Study Studio never restores stale coordinates or leaves lock styles behind.
- **Enterprise mobile sidebar drawer visibility (`public/index-redesign.html`):** Kept `.sidebar` hidden on mobile (`@media (max-width: 768px)`) until `.sidebar.open` applies `visibility: visible; pointer-events: auto;`.

## Technical Changes
- **Version alignment & Service Worker cache (`package.json`, `package-lock.json`, `docker-compose.yml`, `public/sw.js`, HTML pages):** Bumped NexOS to `4.7.0`, Service Worker `CACHE` to `'nexos-shell-v40'`, and versioned asset URLs across `index.html`, `index-redesign.html`, `contact.html`, `privacy.html`, and `sw.js` to `?v=4.7.0` while preserving historical `2.5.1`, `3.x`, and `4.0.0`–`4.6.0` records.
- **Release documentation & test suite consistency (`README.md`, `scripts/`):** Updated `README.md` release-notes links for the `RELEASE-NOTES/RELEASE-NOTES NexOS 4.0/` directory layout, updated version assertions across the verification scripts, and added `scripts/test-product-polish-470.js`.

## Tests & Verification
- **`scripts/test-product-polish-470.js`:** Chrome DevTools Protocol (CDP) end-to-end checks across Classic (`/`) and Enterprise (`/enterprise`) validating Dashboard ordering, `openNoteFromDash`, Kanban `#tag`/overdue filtering and Board/List sync, `#modal-slot-schedule` and `#modal-new-habit` without `window.prompt`, Pomodoro reload persistence and auto-start cancellation, offline Analytics summaries, WCAG contrast across all 5 Enterprise themes, and Desktop (`1440×900`), Tablet (`768×1024`), and Mobile (`360×740`) responsiveness with zero runtime exceptions or console errors.
- **`scripts/test-study-fullpage-460.js`:** Chrome CDP & HTTP suite covering embedded Study Studio geometry, persistent sidebar/topbar and mobile bottom-nav clearance in Classic and Enterprise, wheel/touch scroll isolation, capture-phase `Escape`, Mindmap flow, NexAI continuation, note summarization race protection, CORS `PATCH` preflight, standalone HTML pages, and `4.7.0` release consistency.
- **`npm test` & `git diff --check`:** `15` `node --check` syntax checks and `44` automated Node and Chrome CDP test scripts configured and verified in `package.json`.

## Known Verification Limitations
- Automated server, persistence, AI, and browser tests run locally against in-memory stores and controlled local handlers rather than live external services.
- Live MongoDB Atlas writes, live Google OAuth sign-in, live Google Gemini API calls, live Google Calendar sync, and live VAPID Web Push delivery were **not** tested against production credentials in this environment.
- `npm run lint` (`eslint server.js`) requires a local ESLint configuration not committed in the repository; syntax verification across backend and client JavaScript is executed via `node --check`.

# NexOS 3.1.0 — Cobalt Lime

NexOS 3.1.0 adds a new Enterprise theme. Only `public/index-redesign.html` changed in the app; Classic and the 3.0.3 Recovery Center are untouched.

## Added
- **Cobalt Lime theme (Enterprise).** Midnight black base (`#030407`), electric cobalt blue (`#1558C9`) for cards, borders and hover states, and acid lime (`#D4FF24`) for primary actions and highlights. Choose it from the Enterprise gear menu, under Theme.
- It is saved with your account like the other themes, so it comes back after a refresh and on other devices.

## Notes
- Overgame is still the default theme. Apple Glass, Material, Apple Light, M3 and Overgame are unchanged.
- Buttons on lime use dark text so they stay readable.
- Recently deleted follows the dark look when Cobalt Lime is active.
- No database migration, workspace format change, authentication change or environment-variable update is required.

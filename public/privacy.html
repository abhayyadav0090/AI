NexOS · Privacy

Privacy Policy

Last updated: 26 November 2026

NexOS is a personal productivity workspace created by an independent developer. This page describes what data the application actually collects and stores based on its implemented codebase.

Guest & local preview mode

If you use Continue as guest (or Enterprise local preview), your tasks, habits, notes, timer sessions, and settings are stored only in browser localStorage on your device. They are not sent to the NexOS backend, and server-backed AI and Study Studio uploads are unavailable. Clearing browser storage removes local workspace data unless exported as JSON first.

Google Sign-In & cloud storage

When you sign in with Google, NexOS receives your name, email address, profile picture, and Google account identifier via Google Identity verification. Sign-in does not access your Gmail messages or Google Drive files.

For signed-in accounts, NexOS stores in MongoDB Atlas:

  • Account identity: name, email address, profile picture URL, and session-revocation timestamp.
  • Workspace state: tasks, habits, notes, focus logs, recently deleted items (30-day list), and UI preferences.
  • NexAI conversations: saved chat messages (and uploaded chat attachment text extracted for the reply).
  • Study Studio: extracted text chunks and metadata (not original uploaded PDF binary files), spaced revision cards, exam plans, and saved mindmaps.
  • Reminders (optional): Web Push endpoint/encryption keys and reminder time preference when you enable browser alerts.
  • Google Calendar sync (optional): if you connect Google Calendar inside Study Studio, an encrypted OAuth refresh token is stored solely to sync study blocks until disconnected.

AI processing (Google Gemini)

When you message NexAI or generate Study Studio answers, quizzes, flashcards, or mindmaps, the server sends your prompt (plus recent chat turns and a summary of workspace context, or relevant extracted study chunks) to Google Gemini over HTTPS. Avoid entering passwords or sensitive credentials into AI prompts. How Google retains or processes upstream API inputs depends on the deployment’s configured Gemini API plan and Google’s terms.

Cookies & browser caches

  • One signed httpOnly JWT cookie (token) valid for 7 days to keep you signed in.
  • Browser localStorage and PWA Service Worker cache for fast startup, offline editing caches, and theme preferences. API responses are bypassed by the Service Worker.

Data control & deletion

  • Use Recovery Center (/recover.html) or Settings export at any time to download a JSON backup or restore items.
  • Deleting account data in Settings runs server cleanup removing your workspace state, NexAI chats, Study documents/chunks/reviews/exam plans/mindmaps, Google Calendar link, and Web Push subscriptions, and revokes existing session cookies. Your basic Google sign-in user record remains so you can log in cleanly later; contact the creator via About & Contact if you want that identity row erased as well.
  • No third-party ad networks or analytics trackers are embedded in NexOS HTML pages. Hosting server access logs are governed by the server hosting provider.

NexOS is an independent portfolio and personal productivity project provided as is. Deployment infrastructure policies (hosting and database provider retention) cannot be verified from source code alone.
